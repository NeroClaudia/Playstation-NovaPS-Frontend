# NovaPS – PlayStation rental website

```
novaps/
├── index.html                  Home (guest + logged-in view)
├── pages/
│   ├── login.html
│   ├── signup.html
│   └── forgot-password.html
├── src/                        Tailwind sources (edit these)
│   ├── shared.css              Theme, buttons, variants (imported by every page CSS)
│   ├── index.css               Home-only styles (icon buttons, tooltip, bullets)
│   ├── login.css
│   ├── signup.css
│   └── forgot-password.css
├── css/                        Generated by Tailwind – one file per page
│   ├── index.css
│   ├── login.css
│   ├── signup.css
│   └── forgot-password.css
├── js/
│   ├── shared/
│   │   ├── session.js          Login state (every page)
│   │   └── validation.js       Form validation (login, signup, forgot password)
│   ├── index.js                Pop-up, order buttons, profile menu
│   ├── login.js
│   ├── signup.js
│   └── forgot-password.js
└── package.json
```

Each page loads only its own CSS and JS, plus the shared JS it needs.

## Run

Open `index.html` in a browser. `css/` is already built.

## Edit with Tailwind

```
npm install        # once
npm run dev        # rebuilds every css/*.css while you edit
npm run build      # minified build for final use
```

## Format code (Prettier)

```
npm run format         # format all files
npm run format:check   # only check
```

Install the "Prettier - Code formatter" extension in VS Code; format on save is
already enabled in `.vscode/settings.json`.

Login is a demo (localStorage) until a backend/API is connected.
